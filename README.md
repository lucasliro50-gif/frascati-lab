# Frascati Lab

Protótipo navegável de apoio à análise preliminar de projetos de P&D, concebido para o contexto do Banco do Nordeste.

## Abrir

Abra `index.html` em um navegador moderno. A apresentação funciona sem servidor e inclui 40 casos fictícios, o BNBzinho demonstrativo, modo noturno e exportação de dossiês em PDF e JSON.

## Escopo

As conversas do caso pronto são ilustrativas. A versão de apresentação não faz chamadas a uma API de IA e não contém chaves de acesso. A avaliação técnica exige revisão humana e não representa aprovação do MCTI.

O arquivo inclui os documentos da massa fictícia fornecida para o exercício. Uma publicação pública torna esse conteúdo acessível aos visitantes.

## GitHub Pages

Publique a raiz da branch principal usando GitHub Pages. O arquivo `index.html` já está pronto para esse formato.
